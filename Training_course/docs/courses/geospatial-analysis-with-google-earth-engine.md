## Course guide

Geospatial Analysis with Google Earth Engine is a certificate / intermediate-to-advanced programme built around 11 practical modules. Work through the modules in order; each one includes objectives, notes, a hands-on exercise, a knowledge check, and a deliverable.

### Learning outcomes

1. Use vector and raster data models and coordinate reference systems to work with geospatial data models, crs, and projections and explain the result.
2. Use vector and raster data models and coordinate reference systems to work with python environment setup: conda, jupyter, gdal, and dependencies and explain the result.
3. Use vector and raster data models and coordinate reference systems to work with vector analysis with geopandas and shapely and explain the result.
4. Use vector and raster data models and coordinate reference systems to work with raster processing with rasterio and rioxarray and explain the result.
5. Use vector and raster data models and coordinate reference systems to work with n-dimensional climate and time-series data with xarray and explain the result.
6. Use vector and raster data models and coordinate reference systems to work with publication-quality maps with cartopy and matplotlib and explain the result.

### Prerequisites

- Comfort with files, folders, and basic data tables.
- Introductory knowledge of the relevant tool or programming language.
- Willingness to complete short practical exercises after each module.

### Module 01: Geospatial data models, CRS, and projections

#### Learning objectives

- Explain geospatial data models, crs, and projections and where it fits within Geospatial Analysis with Google Earth Engine.
- Use QGIS or GeoPandas and a CRS transform to complete a small, documented workflow.
- Validate the result, record assumptions, and communicate the main finding clearly.

#### Key concepts

- vector and raster data models
- coordinate reference systems
- spatial queries and overlays
- cartographic layout

#### Lesson notes

Geospatial data models, CRS, and projections is best learned as a repeatable workflow: state the question, prepare the inputs, apply the method, check the output, and communicate the result. Keep the original data untouched and save each processing step so the work can be repeated.

The central ideas in this lesson are vector and raster data models, coordinate reference systems, spatial queries and overlays. Use QGIS or GeoPandas to demonstrate the idea, and use a CRS transform to confirm that the output behaves as expected.

Always confirm the CRS before measuring distance or area; degrees are not metres.

#### Hands-on exercise

1. Write a one-sentence question and define the study area or sample extent for geospatial data models, crs, and projections.
2. Prepare the input data and record its source, date, resolution or scale, and coordinate system where relevant.
3. Apply the main technique with QGIS or GeoPandas: import two layers, align their CRS, run a buffer or clip operation, and produce a labelled map with a legend and scale bar.
4. Validate the result visually and numerically; note any unexpected patterns, missing values, or outliers.
5. Export the final map, table, or figure and write a short interpretation with limitations and next steps.

#### Knowledge check

<details>
<summary>Show questions and answers</summary>

1. **What is the difference between vector and raster data?**  
   Answer: Vector data use points, lines, and polygons; raster data use a grid of cells or pixels.

2. **Why must layers share a CRS before analysis?**  
   Answer: Otherwise distances, areas, and overlays are computed in incompatible coordinate systems.

3. **What does a clip operation do?**  
   Answer: It extracts the part of one layer that falls inside the extent of another layer.

</details>
