Course guide

Satellite Data Analysis with Python is a certificate / intermediate-to-advanced programme built around 7 practical modules. Work through the modules in order; each one includes objectives, notes, a hands-on exercise, a knowledge check, and a deliverable.

Learning outcomes

  1. Use electromagnetic spectrum and platform and sensor characteristics to work with satellite imagery and data formats and explain the result.
  2. Use electromagnetic spectrum and platform and sensor characteristics to work with python basics for geospatial analysis and explain the result.
  3. Use electromagnetic spectrum and platform and sensor characteristics to work with numpy for numerical operations and explain the result.
  4. Use electromagnetic spectrum and platform and sensor characteristics to work with pandas for data manipulation and explain the result.
  5. Use electromagnetic spectrum and platform and sensor characteristics to work with matplotlib for visualization and explain the result.
  6. Use electromagnetic spectrum and platform and sensor characteristics to work with processing raster data (geotiff) and explain the result.

Prerequisites

  • Comfort with files, folders, and basic data tables.
  • Introductory knowledge of the relevant tool or programming language.
  • Willingness to complete short practical exercises after each module.

Full module documents

Module 01: satellite imagery and data formats

Learning objectives

  • Explain satellite imagery and data formats and where it fits within Satellite Data Analysis with Python.
  • Use a satellite scene viewer and band combinations and spectral indices to complete a small, documented workflow.
  • Validate the result, record assumptions, and communicate the main finding clearly.

Key concepts

  • electromagnetic spectrum
  • platform and sensor characteristics
  • spatial/spectral/temporal resolution
  • image interpretation

Lesson notes

satellite imagery and data formats is best learned as a repeatable workflow: state the question, prepare the inputs, apply the method, check the output, and communicate the result. Keep the original data untouched and save each processing step so the work can be repeated.

The central ideas in this lesson are electromagnetic spectrum, platform and sensor characteristics, spatial/spectral/temporal resolution. Use a satellite scene viewer to demonstrate the idea, and use band combinations and spectral indices to confirm that the output behaves as expected.

Do not compare images from different dates or sensors without checking calibration, cloud cover, and spatial resolution.

Hands-on exercise

  1. Write a one-sentence question and define the study area or sample extent for satellite imagery and data formats.
  2. Prepare the input data and record its source, date, resolution or scale, and coordinate system where relevant.
  3. Apply the main technique with a satellite scene viewer: compare at least two band combinations, label three land-cover features, and explain how resolution affects interpretation.
  4. Validate the result visually and numerically; note any unexpected patterns, missing values, or outliers.
  5. Export the final map, table, or figure and write a short interpretation with limitations and next steps.

Knowledge check

Show questions and answers 1. **What does spatial resolution describe?** Answer: The ground size of one pixel; smaller pixels mean finer spatial detail. 2. **Why are near-infrared and red bands useful for vegetation?** Answer: Vegetation strongly reflects near-infrared and absorbs red, making their contrast useful for vegetation indices such as NDVI. 3. **What should be checked before comparing two satellite images?** Answer: Date, sensor, calibration, cloud cover, projection, and spatial resolution.

Deliverable

A one-page practical note containing the question, data description, method steps, one output, and three bullet points of interpretation.

Capstone project

Satellite Data Analysis with Python: Final Applied Project

  1. Choose a focused question related to the course theme and define the study area or sample dataset.
  2. Write a short project brief with data sources, intended method, and expected deliverables.
  3. Complete the processing workflow using at least three methods learned in this course.
  4. Validate the outputs and document every assumption, parameter, and limitation.
  5. Submit a final report with maps or figures, a reproducible workflow, and a concise recommendation.

Final submission: a report, reproducible workflow, maps or figures, and a five-minute presentation.

Assessment rubric

Area Weight Evidence

Module exercises 40% Practical notes, maps, tables, and annotated outputs.
