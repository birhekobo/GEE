Introduction to MATLAB

Get started with MATLAB programming for scientific computing. Learn the fundamentals of the MATLAB environment, scripting, and data analysis in this free introductory course.

Course guide

Introduction to MATLAB is an introductory programme built around 7 practical modules. Work through the modules in order; each one includes objectives, notes, a hands-on exercise, a knowledge check, and a deliverable.

Learning outcomes

  1. Use matrix-based computation and script and function design to work with matlab interface and explain the result.
  2. Use matrix-based computation and script and function design to work with basic commands, variables, and data types and explain the result.
  3. Use vector and raster data models and coordinate reference systems to work with working with vectors and matrices and explain the result.
  4. Use matrix-based computation and script and function design to work with basic plotting and visualization and explain the result.
  5. Use matrix-based computation and script and function design to work with writing your first matlab scripts and explain the result.
  6. Use matrix-based computation and script and function design to work with functions and control flow and explain the result.

Prerequisites

  • Basic computer literacy and a modern web browser.
  • No prior programming experience is required for the introductory lessons.

Module 01: MATLAB interface

Learning objectives

  • Explain matlab interface and where it fits within Introduction to MATLAB.
  • Use MATLAB and built-in numerical functions to complete a small, documented workflow.
  • Validate the result, record assumptions, and communicate the main finding clearly.

Key concepts

  • matrix-based computation
  • script and function design
  • numerical approximation
  • visualisation of results

Lesson notes

MATLAB interface is best learned as a repeatable workflow: state the question, prepare the inputs, apply the method, check the output, and communicate the result. Keep the original data untouched and save each processing step so the work can be repeated.

The central ideas in this lesson are matrix-based computation, script and function design, numerical approximation. Use MATLAB to demonstrate the idea, and use built-in numerical functions to confirm that the output behaves as expected.

Check vector dimensions and convergence criteria; many MATLAB errors come from shape mismatches or stopping too early.

Hands-on exercise

  1. Write a one-sentence question and define the study area or sample extent for matlab interface.
  2. Prepare the input data and record its source, date, resolution or scale, and coordinate system where relevant.
  3. Apply the main technique with MATLAB: implement the method in a script, test it against a simple known case, plot the result, and document error behaviour.
  4. Validate the result visually and numerically; note any unexpected patterns, missing values, or outliers.
  5. Export the final map, table, or figure and write a short interpretation with limitations and next steps.

Knowledge check

Show questions and answers 1. **Why is MATLAB well suited to numerical work?** Answer: It provides matrix operations, numerical libraries, and visualisation in one environment. 2. **Why test a numerical method on a known case?** Answer: It verifies the implementation before applying it to harder problems. 3. **What is convergence in an iterative method?** Answer: The sequence of approximations approaches a stable solution within a tolerance.

Deliverable

A one-page practical note containing the question, data description, method steps, one output, and three bullet points of interpretation.

Module 03: Working with vectors and matrices

Learning objectives

  • Explain working with vectors and matrices and where it fits within Introduction to MATLAB.
  • Use QGIS or GeoPandas and a CRS transform to complete a small, documented workflow.
  • Validate the result, record assumptions, and communicate the main finding clearly.

Key concepts

  • vector and raster data models
  • coordinate reference systems
  • spatial queries and overlays
  • cartographic layout

Lesson notes

Working with vectors and matrices is best learned as a repeatable workflow: state the question, prepare the inputs, apply the method, check the output, and communicate the result. Keep the original data untouched and save each processing step so the work can be repeated.

The central ideas in this lesson are vector and raster data models, coordinate reference systems, spatial queries and overlays. Use QGIS or GeoPandas to demonstrate the idea, and use a CRS transform to confirm that the output behaves as expected.

Always confirm the CRS before measuring distance or area; degrees are not metres.

Hands-on exercise

  1. Write a one-sentence question and define the study area or sample extent for working with vectors and matrices.
  2. Prepare the input data and record its source, date, resolution or scale, and coordinate system where relevant.
  3. Apply the main technique with QGIS or GeoPandas: import two layers, align their CRS, run a buffer or clip operation, and produce a labelled map with a legend and scale bar.
  4. Validate the result visually and numerically; note any unexpected patterns, missing values, or outliers.
  5. Export the final map, table, or figure and write a short interpretation with limitations and next steps.

Knowledge check

Show questions and answers 1. **What is the difference between vector and raster data?** Answer: Vector data use points, lines, and polygons; raster data use a grid of cells or pixels. 2. **Why must layers share a CRS before analysis?** Answer: Otherwise distances, areas, and overlays are computed in incompatible coordinate systems. 3. **What does a clip operation do?** Answer: It extracts the part of one layer that falls inside the extent of another layer.

Deliverable

A one-page practical note containing the question, data description, method steps, one output, and three bullet points of interpretation.

Capstone project

Introduction to MATLAB: Final Applied Project

  1. Choose a focused question related to the course theme and define the study area or sample dataset.
  2. Write a short project brief with data sources, intended method, and expected deliverables.
  3. Complete the processing workflow using at least three methods learned in this course.
  4. Validate the outputs and document every assumption, parameter, and limitation.
  5. Submit a final report with maps or figures, a reproducible workflow, and a concise recommendation.

Final submission: a report, reproducible workflow, maps or figures, and a five-minute presentation.

Assessment rubric

Area Weight Evidence
Participation and preparation 20% Short reflections and completed setup checks.
Module exercises 40% Practical notes, maps, tables, and annotated outputs.
Knowledge checks 20% Quiz responses and corrections.
Capstone project 20% Final report, reproducible workflow, and presentation.
