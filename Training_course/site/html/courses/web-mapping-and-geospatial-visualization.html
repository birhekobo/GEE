Web Mapping and Geospatial Visualization

Build interactive web maps using Leaflet, Mapbox, and other modern mapping libraries. This certificate course takes you from web fundamentals to deploying production-ready interactive maps and geospatial dashboards.

Course guide

Web Mapping and Geospatial Visualization is a certificate / intermediate-to-advanced programme built around 12 practical modules. Work through the modules in order; each one includes objectives, notes, a hands-on exercise, a knowledge check, and a deliverable.

Learning outcomes

Outcome 1Use client-side map architecture and tile layers and web services to work with web mapping technologies and the geospatial web and explain the result.
Outcome 2Use matrix-based computation and script and function design to work with html, css, and javascript fundamentals for mapping and explain the result.
Outcome 3Use client-side map architecture and tile layers and web services to work with using leaflet to create interactive maps and explain the result.
Outcome 4Use vector and raster data models and coordinate reference systems to work with vector and raster tiles, web map services (wms/wmts) and explain the result.
Outcome 5Use client-side map architecture and tile layers and web services to work with geospatial data formats: geojson, geopackage, kml and explain the result.
Outcome 6Use client-side map architecture and tile layers and web services to work with styling and customizing map layers and explain the result.

Prerequisites

  • Comfort with files, folders, and basic data tables.
  • Introductory knowledge of the relevant tool or programming language.
  • Willingness to complete short practical exercises after each module.

Full module documents

Each module is a self-contained lesson that can be taught independently or sequenced into the full certificate programme.

HTML, CSS, and JavaScript fundamentals for mapping is best learned as a repeatable workflow: state the question, prepare the inputs, apply the method, check the output, and communicate the result. Keep the original data untouched and save each processing step so the work can be repeated.

The central ideas in this lesson are matrix-based computation, script and function design, numerical approximation. Use MATLAB to demonstrate the idea, and use built-in numerical functions to confirm that the output behaves as expected.

Check vector dimensions and convergence criteria; many MATLAB errors come from shape mismatches or stopping too early.

Hands-on exercise

  1. Write a one-sentence question and define the study area or sample extent for html, css, and javascript fundamentals for mapping.
  2. Prepare the input data and record its source, date, resolution or scale, and coordinate system where relevant.
  3. Apply the main technique with MATLAB: implement the method in a script, test it against a simple known case, plot the result, and document error behaviour.
  4. Validate the result visually and numerically; note any unexpected patterns, missing values, or outliers.
  5. Export the final map, table, or figure and write a short interpretation with limitations and next steps.
Knowledge check: 3 questions with answers
  1. Why is MATLAB well suited to numerical work?
    Answer: It provides matrix operations, numerical libraries, and visualisation in one environment.
  2. Why test a numerical method on a known case?
    Answer: It verifies the implementation before applying it to harder problems.
  3. What is convergence in an iterative method?
    Answer: The sequence of approximations approaches a stable solution within a tolerance.

Vector and raster tiles, Web Map Services (WMS/WMTS)

Learning objectives

  • Explain vector and raster tiles, web map services (wms/wmts) and where it fits within Web Mapping and Geospatial Visualization.
  • Use QGIS or GeoPandas and a CRS transform to complete a small, documented workflow.
  • Validate the result, record assumptions, and communicate the main finding clearly.

Key concepts

vector and raster data modelscoordinate reference systemsspatial queries and overlayscartographic layout

Lesson notes

Vector and raster tiles, Web Map Services (WMS/WMTS) is best learned as a repeatable workflow: state the question, prepare the inputs, apply the method, check the output, and communicate the result. Keep the original data untouched and save each processing step so the work can be repeated.

The central ideas in this lesson are vector and raster data models, coordinate reference systems, spatial queries and overlays. Use QGIS or GeoPandas to demonstrate the idea, and use a CRS transform to confirm that the output behaves as expected.

Always confirm the CRS before measuring distance or area; degrees are not metres.

Hands-on exercise

  1. Write a one-sentence question and define the study area or sample extent for vector and raster tiles, web map services (wms/wmts).
  2. Prepare the input data and record its source, date, resolution or scale, and coordinate system where relevant.
  3. Apply the main technique with QGIS or GeoPandas: import two layers, align their CRS, run a buffer or clip operation, and produce a labelled map with a legend and scale bar.
  4. Validate the result visually and numerically; note any unexpected patterns, missing values, or outliers.
  5. Export the final map, table, or figure and write a short interpretation with limitations and next steps.
Knowledge check: 3 questions with answers
  1. What is the difference between vector and raster data?
    Answer: Vector data use points, lines, and polygons; raster data use a grid of cells or pixels.
  2. Why must layers share a CRS before analysis?
    Answer: Otherwise distances, areas, and overlays are computed in incompatible coordinate systems.
  3. What does a clip operation do?
    Answer: It extracts the part of one layer that falls inside the extent of another layer.

Web Mapping and Geospatial Visualization: Final Applied Project

The capstone consolidates the course into one applied, portfolio-ready piece of work.

  1. Choose a focused question related to the course theme and define the study area or sample dataset.
  2. Write a short project brief with data sources, intended method, and expected deliverables.
  3. Complete the processing workflow using at least three methods learned in this course.
  4. Validate the outputs and document every assumption, parameter, and limitation.
  5. Submit a final report with maps or figures, a reproducible workflow, and a concise recommendation.
Final submissionA report, reproducible workflow, maps or figures, and a five-minute presentation.
