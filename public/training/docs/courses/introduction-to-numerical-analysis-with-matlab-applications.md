## Course guide

Introduction to Numerical Analysis with MATLAB Applications is a certificate / intermediate-to-advanced programme built around 7 practical modules. Work through the modules in order; each one includes objectives, notes, a hands-on exercise, a knowledge check, and a deliverable.

### Learning outcomes

1. Use matrix-based computation and script and function design to work with fundamentals of numerical analysis and explain the result.
2. Use matrix-based computation and script and function design to work with root finding and solving nonlinear equations and explain the result.
3. Use matrix-based computation and script and function design to work with interpolation and curve fitting techniques and explain the result.
4. Use matrix-based computation and script and function design to work with numerical integration and differentiation and explain the result.
5. Use matrix-based computation and script and function design to work with solving systems of linear equations and explain the result.
6. Use matrix-based computation and script and function design to work with numerical solutions to ordinary differential equations and explain the result.

### Prerequisites

- Comfort with files, folders, and basic data tables.
- Introductory knowledge of the relevant tool or programming language.
- Willingness to complete short practical exercises after each module.

## Full module documents

### Module 01: Fundamentals of numerical analysis

#### Learning objectives

- Explain fundamentals of numerical analysis and where it fits within Introduction to Numerical Analysis with MATLAB Applications.
- Use MATLAB and built-in numerical functions to complete a small, documented workflow.
- Validate the result, record assumptions, and communicate the main finding clearly.

#### Key concepts

- matrix-based computation
- script and function design
- numerical approximation
- visualisation of results

#### Lesson notes

Fundamentals of numerical analysis is best learned as a repeatable workflow: state the question, prepare the inputs, apply the method, check the output, and communicate the result. Keep the original data untouched and save each processing step so the work can be repeated.

The central ideas in this lesson are matrix-based computation, script and function design, numerical approximation. Use MATLAB to demonstrate the idea, and use built-in numerical functions to confirm that the output behaves as expected.

Check vector dimensions and convergence criteria; many MATLAB errors come from shape mismatches or stopping too early.

#### Hands-on exercise

1. Write a one-sentence question and define the study area or sample extent for fundamentals of numerical analysis.
2. Prepare the input data and record its source, date, resolution or scale, and coordinate system where relevant.
3. Apply the main technique with MATLAB: implement the method in a script, test it against a simple known case, plot the result, and document error behaviour.
4. Validate the result visually and numerically; note any unexpected patterns, missing values, or outliers.
5. Export the final map, table, or figure and write a short interpretation with limitations and next steps.

#### Knowledge check

<details>
<summary>Show questions and answers</summary>

1. **Why is MATLAB well suited to numerical work?**  
   Answer: It provides matrix operations, numerical libraries, and visualisation in one environment.

2. **Why test a numerical method on a known case?**  
   Answer: It verifies the implementation before applying it to harder problems.

3. **What is convergence in an iterative method?**  
   Answer: The sequence of approximations approaches a stable solution within a tolerance.

</details>

#### Deliverable

A one-page practical note containing the question, data description, method steps, one output, and three bullet points of interpretation.
