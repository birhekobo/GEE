## Course guide

Web Mapping and Geospatial Visualization is a certificate / intermediate-to-advanced programme built around 12 practical modules. Work through the modules in order; each one includes objectives, notes, a hands-on exercise, a knowledge check, and a deliverable.

### Learning outcomes

1. Use client-side map architecture and tile layers and web services to work with web mapping technologies and the geospatial web and explain the result.
2. Use matrix-based computation and script and function design to work with html, css, and javascript fundamentals for mapping and explain the result.
3. Use client-side map architecture and tile layers and web services to work with using leaflet to create interactive maps and explain the result.
4. Use vector and raster data models and coordinate reference systems to work with vector and raster tiles, web map services (wms/wmts) and explain the result.
5. Use client-side map architecture and tile layers and web services to work with geospatial data formats: geojson, geopackage, kml and explain the result.
6. Use client-side map architecture and tile layers and web services to work with styling and customizing map layers and explain the result.

### Prerequisites

- Comfort with files, folders, and basic data tables.
- Introductory knowledge of the relevant tool or programming language.
- Willingness to complete short practical exercises after each module.

#### Hands-on exercise

5. Export the final map, table, or figure and write a short interpretation with limitations and next steps.

#### Knowledge check

<details>
<summary>Show questions and answers</summary>

1. **What is the difference between vector and raster data?**  
   Answer: Vector data use points, lines, and polygons; raster data use a grid of cells or pixels.

2. **Why must layers share a CRS before analysis?**  
   Answer: Otherwise distances, areas, and overlays are computed in incompatible coordinate systems.

3. **What does a clip operation do?**  
   Answer: It extracts the part of one layer that falls inside the extent of another layer.

</details>
